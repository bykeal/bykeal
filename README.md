## 👨‍💻 About Me

Machine learning practitioner focused on **computer vision** and **medical image analysis**. My dissertation compares supervised CNNs, Vision Transformers and BLIP-2 style contrastive models for **malaria blood-smear classification**, with explainability (**Grad-CAM** and **Q-Former cross-attention**) used to check what each model actually looks at.

### 🎯 Core Expertise
- **Computer Vision**: Image classification, CLAHE preprocessing, transfer learning
- **Deep Learning**: Fine-tuning ResNet-18/50/152, VGG-19 and ViT-B/16
- **Multimodal Learning**: Image-text contrastive (ITC) training with a Q-Former on a frozen BLIP-2 ViT-g/14
- **Explainable AI**: Grad-CAM heatmaps and attention visualisation for model interpretability
